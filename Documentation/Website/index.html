WHY EventBus

Loose coupling without losing the plot

Move beyond webs of direct calls and publishers. EventBus gives service coordination a consistent vocabulary and a maintainable future.

Strongly typed events

Events are Swift types. Routing mismatches detected at compile-time.

Concurrency by declaration

Choose .parallel, .serial, or .restart for each handler instead of cut-and-paste task control.

Workflows you can trace

Follow nested event history across multi-step async processes, including timeouts and structured errors.

Designed for testing

Keep services independent from the bus and test event-driven workflows with dedicated support utilities.

Broadcast or request-response

Fan events out to listeners or await a typed response inline with async sendAndWait functions.

Less integration boilerplate

Protocols, extensions, and macros keep event declarations compact and reusable as systems grow.

Get started

Add EventBus to your project with Swift Package Manager.

Package.swift Version 0.9.0 
dependencies: [
    .package(
        url: "https://github.com/siriusxm/swift-event-bus.git",
        from: "0.9.0"
    )
