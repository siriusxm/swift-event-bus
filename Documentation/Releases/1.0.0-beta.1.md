# EventBus 1.0.0-beta.1

`1.0.0-beta.1` is the first public release of `EventBus` and the supported preview for the upcoming 1.0 release.

`EventBus` provides a shared, strongly typed event channel for coordinating asynchronous Swift services without coupling them directly. This beta makes the package available for public integration, evaluation, and API feedback before the stable release.

## Highlights

- Strongly typed broadcast and request-response events.
- Inline request-response workflows built on Swift `async`/`await`.
- Declarative `.parallel`, `.serial`, and `.restart` handler concurrency.
- Cancellation, timeout, error-propagation, and nested event-history support.
- Macros and protocol extensions for compact event and handler declarations.
- `EventBusTestSupport` utilities for testing event-driven systems.
- DocC conceptual guides and API reference.

## Requirements

- Swift 6.2 or later.
- iOS 16 or later.
- tvOS 16 or later.
- macOS 13 or later.
- watchOS 10 or later.

## Installation

Use the exact prerelease version with Swift Package Manager:

```swift
dependencies: [
    .package(
        url: "https://github.com/siriusxm/swift-event-bus.git",
        exact: "1.0.0-beta.1"
    )
]
```

Then add the library product to your target:

```swift
.product(name: "EventBus", package: "swift-event-bus")
```

The package is distributed from its Git tag as source; no separate binary artifact is required.

## Beta status

This release establishes the `EventBus` 1.0 public API. SiriusXM intends to preserve source compatibility from `1.0.0-beta.1` through the stable `1.0.0` release. During the public beta, development will focus on real-world validation, documentation, reliability, and backward-compatible improvements so adopters can move forward without disruptive migration churn.

There is no planned date for `1.0.0`. The stable release will follow a period of public availability and evaluation.
